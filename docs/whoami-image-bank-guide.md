# 「馒头我是谁」高难图片题库批量制作要求

## 任务

给 QQ 群机器人「馒头」的 `/馒头我是谁` 批量追加看图猜角色题。每题只发一张灰度特写，玩家通过服饰细节推断角色。把新题追加到 `nonebot_plugin_mantou_affection/resources/whoami_puzzles.json` 的 `entries`，把对应素材放进同目录下的 `whoami_images/`。保留已有题目和玩法，具体数量按本次委托执行。

- 游戏范围为《原神》《崩坏：星穹铁道》《绝区零》。只出这三款游戏的角色题，排除《崩坏3》、地点、场景和纯文字题。
- 每个角色只收一道题。同一角色的不同皮肤、形态和常见称呼共用一个答案，追加前与已有题库查重。数量允许时，优先补当前较少的游戏，兼顾热门角色和较少出场的角色。
- 用能确认角色及服装归属的现有素材出题，例如已有素材、游戏截图或允许用于题库的角色图。出现角色名、标志或花字时，另选取景。对不上角色的素材直接跳过。

## 难度和取景

按**小范围裁切后的灰度图**判断难度。从装饰花纹、刺绣、衣缝、领扣、搭扣、衣带、金属件等细节中，每题选一个有辨识度的局部。让熟悉该角色设计的玩家有机会凭一个具体形状或纹样认出来。

| 通过 | 退回重裁 |
| --- | --- |
| 一截有独特走线的衣带，或带少量相邻布料的扣件 | 完整人物剪影、头肩轮廓、脸、眼睛、发型、大半件衣服 |
| 裁到一部分的刺绣图案，灰度下还能看清形状 | 一眼认出的招牌武器、完整徽记、能直接读到名字的文字或水印 |
| 灰度下仍有一两处可核对的特征 | 只剩普通布料、大片空白、看不出结构的模糊像素 |

如果看一眼就能猜出，继续收紧取景，或换到同一件衣服上较少被注意的细节。如果连拿着原图对照都很难定位，稍微放宽，留一点相邻纹样。用裁切和灰度控制难度，保持线条清晰。题图内不放游戏名、角色名、文字线索、题号或答案图，也不准备后续提示图。

## JSON 与素材

题库是 UTF-8 JSON，根对象包含 `entries` 数组。下方是仓库里已有的题目，用来说明格式，批量生成时不用再录入这一题。

```json
{
  "entries": [
    {
      "answer": "胡桃",
      "game": "原神",
      "category": "character",
      "aliases": ["往生堂主"],
      "image": "whoami_images/11.png",
      "crop": [371, 440, 516, 556]
    }
  ]
}
```

| 字段 | 填写规则 |
| --- | --- |
| `answer` | 角色的官方简体中文名。 |
| `game` | 固定填写 `原神`、`星穹铁道`、`绝区零` 之一。 |
| `category` | 固定为 `character`。 |
| `aliases` | 玩家常用且指向唯一角色的简称、称号或译名。没有就填 `[]`。别名与正式名共用一个索引，须检查整个题库是否冲突。 |
| `image` | 相对 JSON 所在目录的本地 PNG、JPEG 或 WebP 文件，例如 `whoami_images/026.png`。新文件用未占用的编号，使用实际文件扩展名。 |
| `crop` | 必填 `[左, 上, 右, 下]` 四个整数，基于交付素材文件的像素坐标。左上角为原点，右、下边界不包含在裁切结果内。 |

裁切框必须满足 `0 <= 左 < 右 <= 图片宽度` 和 `0 <= 上 < 下 <= 图片高度`。插件按这个范围裁切并转为灰度 PNG，长边不足 320 像素时等比放大。优先保留足够清晰的素材来裁切，可以先把源图缩小到合理尺寸再定坐标，最终坐标必须对应交付文件。漏掉 `crop` 会绕过裁切和灰度处理，所以每道新题都要有这个字段。

查重时以 `normalize_guess` 的处理为准。全角半角、大小写、空格和标点的差异都可能被归一化。避开会在聊天中频繁出现的通用词和能指代多人的外号，减少把闲聊误记为猜错的情况。

## 批量验收与交付

1. 先做一小批并预览**实际发给群友的图**，用现有灰度题的取景作参考。确认难度后再扩大批次。
2. 逐条对照角色原图，确认答案、游戏、别名与画面一致。检查实际输出没有露出脸、轮廓、答案或额外提示，灰度下仍有可辨认的细节。
3. 合并原有和新增条目进行去重和校验。JSON 能正常解析，素材均存在且可解码，裁切框在界内。核对加载后可用题数等于清单题数，防止坏图被跳过。
4. 在项目根目录运行 `poetry run pytest -q tests/test_whoami.py`。交付更新后的题库 JSON、所有新增素材，以及按游戏统计的新增数量。简要记录素材来自哪里，以及因素材或难度不合格而跳过的条目。

玩法沿用现有设定。每局一张图，默认 75 秒后揭晓，每人只猜一次，答对 +5、猜错 −2、触发者整局未答 −1。制作题库时只更新数据与素材。
