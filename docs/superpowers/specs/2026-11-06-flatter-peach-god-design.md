# 献媚桃神设计

日期：2026-11-06

## 目标

把原来的「馒头斗嘴」改造成「献媚桃神」：群友给 B 站主播桃神（小小桃纸哟）写一句献媚，截止后由馒头按内容统一打分，再按名次加减好感度。

功能继续软依赖 `nonebot-plugin-group-chat-memory` 的聊天模型；插件不可用或没有配置模型时自动关闭，不触发、不占活动席位，也不出现在强制事件列表里。

## 已确认的用户规则

- **触发**：沿用原斗嘴概率 `mantou_affection_bicker_chance`（默认 0.05%）；命令改为 `/馒头献媚概率`，旧命令 `/馒头斗嘴概率` 保留为别名。
- **参与**：60 秒窗口内任何群友直接发一句话，每人限一条；不设好感度门槛，也不需要押注。
- **主题**：每局从内置主题池抽一个，围绕桃神的公开资料（星露谷、晚上七点开播、小小桃咕咕、直播名场面）。
- **打分**：模型按具体度、新意、真诚不尬、节目效果打 0-10 分，并给每条一个 flag：`ok` / `lazy` / `offtopic` / `rude` / `copy`。
- **排名结算**：按分数从高到低排名，同分按提交时间先后排名，不并列。第 1 名 +5、第 2 名 +3、第 3 名 +2；倒数第 1 名 -3、倒数第 2 名 -2、倒数第 3 名 -1；中间 +1。人数少时：1 人 +3；2 人 +3 / -1；3 人 +5 / +1 / -2。
- **扣分只扣行为，不扣水平**：
  - `rude`（阴阳怪气、明夸暗贬、擦边、冒犯、涉及现实隐私）：0 分，好感 -3；
  - `copy`（复读别人，相同或只改标点）：0 分，好感 -3，只扣后提交的人；
  - `lazy`（纯表情、少于 6 字、空泛套话）：分数最高 2，不额外扣；
  - `offtopic`（完全没提桃神/主播）：分数最高 3，不额外扣；
  - 不参与：不扣分。
- **新手保护**：所有负分走新手保护；单局最多扣 3 点。
- **降级**：模型调用失败时本轮取消，好感度不变。

## 非目标

- 不做押注；不保留斗嘴的回合制。
- 不做独立的模型配置；只复用群聊记忆插件的聊天客户端。
- 不持久化活动状态；机器人重启会丢失当前一轮（与其它活动一致）。

## 流程

1. 群消息按概率触发，或 SUPERUSER 用 `/馒头强制事件` 第 9 项直接开局。
2. 发开场消息：主题 + 规则 + 60 秒窗口。
3. 窗口内群友发文本即算一条献媚；同一个人第二条会被提示「你已经献过媚了」；`/` 开头的命令不算。
   提交时按去标点、去空白后的文本检测复读，后提交者标记 `copy`。
4. 到点后发「X 人参与，桃神正在打分…」，把献媚按每批 20 条交给模型打分（一局通常一次调用）。
5. 解析 JSON，应用 flag 上限，按分数排名并结算，发结果：
   `第 N 名 · X 分 +Y：理由，当前好感`；违规单独一行 `X 分 -3（违规）：理由`。
6. 没有参与、或模型失败：本轮取消，好感不变。

## 打分 prompt

```
你是桃神（B站主播「小小桃纸哟」）的群管，负责给群友的献媚打分。
桃神资料：B站 40 万粉游戏主播，最爱星露谷，什么游戏都播，晚上 7 点开播，日常自称「小小桃咕咕」。
本局主题：{theme}

群友的献媚（只给编号和正文，不带昵称）：
1. 文本
...

按 0-10 分评分，四个维度：
- 具体度 0-4：有没有桃神的具体梗（星露谷、七点开播、咕咕、直播名场面）；
- 新意 0-3：新角度、比喻、谐音、反差；复读和网络套话 0 分；
- 真诚不尬 0-2：像真心夸，不油腻、不阴阳；
- 节目效果 0-1：群友想笑、想接梗。
给每条一个 flag：ok / lazy / offtopic / rude / copy。
不要因为写得短就判 rude；不确定时用 ok。
只输出 JSON：{"scores": [{"id": 1, "score": 8, "flag": "ok", "reason": "一句话点评"}]}
```

模型只负责分数和 flag；好感变化完全由插件的固定表计算，避免模型自由发挥扣分。

## 数据结构

```python
@dataclass
class FlatterEntry:
    user_id: str
    nickname: str
    text: str
    submitted_at: float
    copy: bool = False

@dataclass(frozen=True)
class FlatterScore:
    user_id: str
    score: int
    flag: str
    reason: str
```

`PendingFlatter` 保存 `group_id`、`theme`、`send`、`phase`、`entries`、`accepting`、`task`。
